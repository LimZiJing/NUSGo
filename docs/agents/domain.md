# Domain Docs

This repository uses a single-context layout.

Before exploring a task, read:

- `CONTEXT.md` at the repository root for domain language.
- `docs/project-status.md` when current implementation status is relevant.
- Relevant ADRs under `docs/adr/`, if they exist.

Use the project's glossary vocabulary from `CONTEXT.md` in issue titles, plans, and test names.

If an issue conflicts with an ADR, identify the conflict explicitly.
